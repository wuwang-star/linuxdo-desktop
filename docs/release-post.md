# 「下载即用」的 linux.do Windows 桌面客户端 —— 内置 ECH 直连，免配置代理

**一句话**：不用装 Clash、不用改 DNS——下载、双击、登录，就能刷 linux.do。

## 它解决什么

linux.do 走 Cloudflare，大量家庭宽带线路存在 **DNS 污染 + SNI 阻断**：网页打不开、第三方客户端全都要「自备代理环境」。LinuxDo Desktop 把代理这件事内置了：

- 🛡 **ECH 直连引擎**：TLS 握手层加密服务器名称（Encrypted Client Hello），从根上绕开 SNI 阻断；首次启动自动完成「DNS → ECH → 连通」三步检测，全 Tight 集成无需任何操作
- 🔍 **网络诊断**：任何连接问题，诊断面板给结论 + 下一步动作，永远不让你对着报错码发呆
- 🧭 **降级指引**：极端线路也有图文出口（接入已有代理 30 秒可配），不玩失踪

## 为长阅读而生

- 📖 **双栏主从**：左侧帖子列表 + 右侧正文同屏，列表可拖宽、可按浏览量排序
- 🌳 **楼中楼折叠**：回复串原位展开三级缩进，「只看楼主」一键过滤
- 📴 **离线阅读**：帖子快照存本地，断网也能看
- 🎨 **正文排版**：飞书文档级排版规范（15px/1.7 行宽锁 720px），代码块/引用/表格全适配

## 账号与数据

- 🔑 **登录三方式**：浏览器窗口（全功能）/ Connect 授权（最快 5 秒）/ 账号密码（可记住自动填充，支持 2FA）——能力差异写在选择页上
- 🔖 **多收藏夹**：自建任意多个夹，快照离线可看
- ☁️ **WebDAV 云同步**：收藏夹 + 阅读进度换机不丢
- 🔎 全文搜索 / 最热榜六档 / 未读通知原生提醒

## 外观

- 🎭 **主题工坊**：纯 CSS 皮肤包体系，内置精品样例；亮 / 暗 / 跟随系统
- 整站统一设计规范（字号阶梯 / 间距网格 / 动效三档），飞书系阅读排版
