# LinuxDo Desktop 路线图

> 2026-10-20 用户拍板（grill 五问）。**此后每个新功能立项必须挂本文档出处**，挂不上的默认不做。

## 北极星

**面向 linux.do 社区发布的公共 Windows 桌面客户端**。不是自用工具，不是平台化底座——判断标准：新用户（无任何自备代理环境的普通人）下载后能否顺畅用起来。

## 发布主张

**"下载即用，免配置"**——内置 ECH 直连引擎根治 SNI 阻断，这是与 FluxDO 等参照品（均需自备代理）的最硬差异化。ECH 是主打卖点，也是**发版门神**：盾过不稳就不发。

## v1.0 范围（2026-10-20 划线）

**进**：
- 阅读：双栏主从 / 楼中楼树形 / 离线 Topic / 排版主题 / 内链跳转
- 网络：ECH 直连（主打）+ DoH + 网络诊断与降级指引
- 账号：登录窗口三方式 + User API Key（站点开放即启用）+ 记住账密自动填充
- 数据：搜索 / 最热 Top 六档 / 多收藏夹 + WebDAV 云同步
- 外观：主题工坊（含 2-3 个精品皮肤）+ 全站 UI 规范 tokens
- 底座：安装向导 / 窗口壳 / 托盘

**出**（代码保留，入口移除或藏为实验开关）：
- 多主题队列——价值未经验收，社区维护负担黑洞；v1.x 视反馈评估回归
- kb-api（AI 数据接口）——平台化种子，与 v1.0 主线无关，v1.x 单独立项
- 办公软件皮肤系列——主题工坊留精品样例即可

## 发布门槛（v1.0 硬线）

1. **ECH 可靠性**：多网络环境（至少 3 种运营商/线路）过盾稳定，挑战自动化链路无人工干预通过；失败时有明确的诊断与降级出口（提示自备代理）
2. **验收债清零**：所有"已交付待验收"功能的 AC 真机过一遍（搜索 / 收藏夹同步 / 双栏 / 用户流 / UI 规范 / 登录账密等）
3. **发布基建**：electron-builder 打包安装器 + electron-updater 自动更新（原 AC5）可用
4. 无已知崩溃 / 数据丢失（收藏夹、离线缓存）

## 发布基建决策（已拍板）

- 渠道：**GitHub Releases 主渠道**，linux.do 发布帖引流
- 自动更新：**electron-updater 走 Releases 检更**
- 签名：**不买证书，裸发**，发布帖附 SmartScreen 放行引导；社区规模起来后复评
