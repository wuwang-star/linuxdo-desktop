# 评论树形展示（楼中楼视图）

## Goal

阅读页提供「时间流 / 树形」双视图切换。树形按 `reply_to_post_number` 把回复聚合到父楼之下形成嵌套楼中楼——用户 2026-10-16 指令（参考 FluxDO 楼中楼/ALDR 完整讨论上下文，仅参考行为）。

## Background（已确认事实）

- 帖子数据自带 `reply_to_post_number`（client.ts 已解析）；当前为纯时间流 + reply_to 引用跳转。
- 分块懒加载：任意时刻只有部分楼层在内存；被回复的父楼可能未加载。
- 只看楼主过滤与树形需共存；阅读宽度限制下嵌套缩进空间有限。

## Requirements

- **R1 双视图切换**：TopicView 副标题行「时间流 / 树形」分段切换；偏好存入 `ldd-reading`（prefs.ts 增 `viewMode`，默认时间流）。
- **R2 树形聚合**：按已加载楼层构建 `post_number → children` 映射；根=无 reply_to 或父楼未加载；同层按楼层号排序；深度缩进上限 3 层（更深层续用第 3 层缩进+引导线）。
- **R3 兼容**：只看楼主在树形下对过滤后集合重建树；向上加载更早楼层后树重建；互动（回复/点赞/编辑）在树形下不变。
- **R4 缩进呈现**：每层左缩进 16px + 左引导线（border-left），nested 容器不影响 cooked 排版变量。

## Acceptance Criteria

- [ ] **AC1** 树形视图：直接回复嵌在父楼下、链式回复逐层缩进（≤3 层），切换偏好重启保留。（人工）
- [ ] **AC2** 父楼未加载的回复作为根显示并带「回复 #N」标记；向上加载补齐父楼后自动归位。（人工）
- [ ] **AC3** 只看楼主 + 树形组合可用；时间流视图行为与现状完全一致。（人工）
- [x] **AC4** 双栏右栏与窄屏整页下均正常；`pnpm run typecheck` 0 错；`pnpm run smoke` SMOKE_OK。

## Out of Scope

- 单楼「查看对话」链式视图（Discourse thread 端点，后续）
- 树形下折叠/展开子回复（默认全展开，后续按反馈加）
