# 双栏浏览：列表+阅读主从布局

## Goal

宽屏（≥1200px）下列表与阅读左右双栏并置：左栏列表常驻（滚动位置不丢），右栏阅读；点击列表项右栏即时切换主题。窄屏回退现有整页导航。这是 roadmap MVP 重点「连续阅读工作区」的桌面主从形态（参考 FluxDO 主从布局 / ALDR 左右嵌入，仅参考行为）。

## Background（已确认事实）

- 现状：`/`（HomeView 列表）与 `/t/:id`（TopicView 阅读）整页互切，列表滚动位置丢失；队列上一贴/下一贴同样整页跳转。
- TopicView 从 `useRoute().params.id` 取主题；topic store 单主题态（同屏只有一个主题，右栏复用安全）。
- 通知/队列跳转带 `/t/<id>?pn=<n>`；离线阅读带 `?offline=1`；HomeView 已有 `offline` 列表模式。

## Requirements

- **R1 双栏**：视口 ≥1200px 时 `/` 与 `/t/:id` 均渲染 BrowseView：左栏列表（复用 HomeView 列表，宽 ~400px，自带滚动）+ 右栏 TopicView；列表点击 → 右栏加载，URL `router.replace('/t/<id>')` 保持可分享/可回跳；列表滚动位置与筛选状态全程保留。
- **R2 窄屏**：<1200px 回退现有行为（列表整页 → 点进整页阅读，浏览器返回回列表）。
- **R3 兼容**：队列上一贴/下一贴、通知 `?pn=` 直达楼层、离线 `?offline=1`、话题内回复/点赞/编辑全部在双栏下工作。
- **R4 右栏空态**：`/` 且未选主题时右栏显示占位（logo+提示「从左侧选择主题」）。

## Acceptance Criteria

- [ ] **AC1** ≥1200px：点左栏主题 → 右栏加载，左栏滚动位置与「离线/分类」筛选不变；连续点多个主题右栏依次切换。
- [ ] **AC2** 双栏内队列 上一贴/下一贴 正常切换右栏；通知跳转（含 ?pn）在双栏下直达楼层。
- [ ] **AC3** 窗口缩到 <1200px 回退整页导航，拉宽恢复双栏且右栏保持当前主题。
- [ ] **AC4** 离线列表点击 → 右栏离线阅读（无网络请求）。
- [x] **AC5** `pnpm run typecheck` 0 错；`pnpm run smoke` SMOKE_OK。

## Out of Scope

- 可拖拽分隔条调节栏宽（后续）
- 多主题并排/多标签
- 双栏下的划词引用等增强
