# 飞书版 IM 外框架改版

## Goal

顶栏删除改飞书式外框架：左 rail+飞书化列表栏+白底内容区+thread 折叠楼中楼，配色走 tokens。

用户已通过 grill-me 全流程拍板所有决策，并验收过高保真 mockup（research/feishu-im-frame-mockup.html，视觉基准）。

## Requirements

- R1 顶栏整体删除；左侧导航 rail 常驻全局：头像/登录（已登录点头像开 UserCard）→ 最新 → 队列（数字徽标）→ 通知（未读徽标）→ 底部设置；rail 支持收起/展开（展开≈184px 带文字标签，收起 56px 纯 icon，状态存 prefs）；rail 顶部搜索框（头像下），承接现有搜索 MVP 交互。
- R2 中栏列表飞书化：每行=作者头像+帖标题+摘要行+时间右对齐（今天=时刻、更早=日期）+选中态蓝底高亮；「帖子」节头+筛选 icon+最新/热门/Top 六档工具条保留并吸顶。
- R3 内容区白底通铺（非浮卡）：标题+meta 行（分类/楼层/浏览）+页签行（「正文」默认激活、「只看楼主」可切换过滤）+动作（回复/入队/离线）；未选主题时空态占位页。
- R4 楼中楼重做：thread 折叠式为唯一模式，删除时间流/树形切换（viewMode 偏好废弃）；**回复串默认展开**，层级缩进可见到三级（串根=1级、根的直接回复=2级、回复的回复=3级，更深层级平铺续接并用「回复 #N」chip 表达引用关系）；折叠钮保留（「收起/展开 N 条回复」），默认态=展开，不持久化；聚类规则=有 reply_to 的挂 parent 所在串，无 reply_to 的留主干；「楼主」角标。（用户 2026-10-17 反馈修订：原「默认折叠」改「默认展示三级回复」）
- R5 覆盖面：设置/通知/用户主页打开时 rail 常驻、内容区整宽切换（中栏隐藏）；登录页/未登录=rail 灰态。
- R6 窗口三钮（自绘：最小化/最大化/关闭=托盘）改为悬浮窗口右上角；拖拽区=rail 顶部+中栏节头+内容区头部；双击拖拽区最大化保留。
- R7 配色：默认=飞书群公告页色调（浅灰底+白卡+蓝点缀），全部经 tokens.css 变量，标记为临时方案（用户后续会改）；暗色=同结构映射深色 tokens，不出独立设计；主题工坊皮肤可继续叠加。
- R8 右栏楼层展示面板：本版不做（用户拍板默认关、功能后续重新定义）；内容区即帖子阅读位。
- R9 per-topic 未读徽标不做（无已读数据源）。
- R10 rail「＋」新建钮仅占位（无新功能）。
- R11 正文阅读优雅化（用户 2026-10-17「完成所有工作」拍板折入，参考 research/content-reading-reference.md 四项目源码参数）：① 正文列 max-width≈720px 居中，不通铺；② 动作行降噪——无内容的次级动作（回复/译）默认低透明度、楼层 hover/focus-within 显现，有内容的常显（赞数>0、可编辑钮）；③ 引用块重做=浅灰底+左色条 4px 卡片（弃蓝底），标题行 24px 小头像+用户名，正文 max-height 220px 默认折叠+展开钮+跳原楼；④ 排版基线：正文 15-16px/1.6、meta 12px muted、楼层发丝线+12px 顶距、头像 40px。
- R12 动效系统（用户 2026-10-17「弹出等动效做一下设计」）：tokens 化三档时长（fast 120ms/base 180ms/slow 240ms）+ ease-out 曲线 + prefers-reduced-motion 全局降级；覆盖=队列浮层开合、lightbox 开合、thread 展开、整宽页路由切换、rail 收起（统一到 tokens）、行级 hover 渐变。原则：只动 opacity/transform 不动布局属性，无弹跳无循环。
- R13 功能页继续打磨（「查看主页的功能页面继续开发」按「rail 进的功能页」理解）：通知/设置/用户页在安全区+新 tokens 下统一间距与 hover 渐变；空态/加载态样式与壳一致。属轻打磨，结构性重设计不在本批。

## Acceptance Criteria

- [ ] AC1 启动后无顶栏；rail 五项+搜索框+收起/展开可用且状态重启保留；窗口三钮悬浮右上、关闭=隐藏到托盘。
- [ ] AC2 列表行为飞书解剖（头像/标题/摘要/时间/选中态），工具条与节头吸顶，最新/热门/Top 六档行为与改版前一致。
- [ ] AC3 点列表行帖子在内容区打开，URL /t/:id 同步语义与改版前一致（双栏 replace、窄屏 push）；空态占位显示。
- [ ] AC4 楼层流为主干+回复串；**串默认展开且三级缩进可见**；点「收起/展开 N 条回复」切换正常；「只看楼主」过滤正确（主干+子楼都过滤）；楼主角标正确。
- [ ] AC5 设置/通知页整宽切换且 rail 常驻高亮；未登录 rail 头像为灰态。
- [ ] AC6 亮色=群公告色调；切暗色不炸（tokens 映射）；主题工坊切换皮肤仍生效。
- [ ] AC7 拖拽区可拖动窗口、双击最大化；rail/中栏/内容区内控件不受拖拽区误吞。
- [ ] AC8 `npm run typecheck` 与 `npm run build` 通过。
- [ ] AC9 正文列居中封顶约 720px；动作行 hover 显现且常显项正确；引用块=左色条灰卡+超长折叠+展开/跳转可用；字号/间距基线生效。

## Out of Scope

- 右栏面板重定义（后续任务）
- per-topic 未读徽标、新建主题功能
- 微信/QQ 等「IM 系列」其他皮肤变体
- 主题工坊新增皮肤包

## Constraints

- 多会话协同：`.trellis/workspace/coordination.md` 铁律适用——App.vue/router/index.ts 为公用文件；styles 走部位文件（新建 shell 类部位文件承载 rail/壳样式），tokens.css/base.css 底座不动（tokens 允许追加变量组）。
- 摘要行数据源约束：latest.json 无正文摘录（blurb 仅搜索端点有），禁止为摘要新增网络请求；用列表已有字段组合（见 design.md）。
