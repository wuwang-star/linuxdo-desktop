# 登录页信息架构重排

## Goal

登录页现有四个方式平铺 + 每个都有授权按钮，用户曾误点方式三死通道（linux.do 已禁用 user_api_key）。按推荐度重排信息架构：推荐通道首屏放大，次级与死通道折叠，减少误点。纯布局重排，**不改任何逻辑**。

## Background

- 现状 LoginView 平铺：方式一浏览器窗口登录（推荐）+ Edge 扩展桥接行、方式二 _t 注入、方式三 User API Key（站点禁用，死通道）、方式四手动 Api-Key、LINUX DO Connect 身份组。
- 用户实测误点方式三 → 死页面造成困惑（2026-10-16）。

## Requirements

- R1 层级：① 登录状态卡（不变）→ ② **方式一卡片放大置顶**（浏览器窗口登录按钮 + Edge 扩展桥接行 + 安装向导按钮，标注「推荐」）→ ③ **Connect 身份卡**（次级）→ ④ 「高级 / 其他方式」默认折叠区（内含：_t 注入、方式三〔标注「已禁用」徽标〕、方式四）。
- R2 折叠区用 details/summary 或等价原生实现，展开态记忆到本次会话即可（不持久化）。
- R3 所有既有入口与逻辑保留（含每卡的保存/授权按钮行为），仅移动与分组。
- R4 登录状态卡、顶栏、设置入口不动。

## Acceptance Criteria

- [ ] AC1 首屏（1080p 不滚动）可见：登录状态 + 方式一（含桥接）+ Connect 入口。（待人工）
- [ ] AC2 方式三默认不可见，展开高级区后可见且带「已禁用」标识；其余入口全部仍可达。（待人工）
- [ ] AC3 各方式功能行为与重排前一致（桥接开关/向导/Connect 授权/_t 注入/手动 Key）。（待人工；模板只移动容器，script/IPC 零改动）
- [x] AC4 `pnpm run typecheck` 0 错；`pnpm run smoke` SMOKE_OK。（2026-10-16 实测通过）

## Out of Scope

- 任何登录逻辑/IPC 变更；设置中心布局；新功能。
