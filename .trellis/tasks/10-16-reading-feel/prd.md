# 阅读体感：排版与主题偏好

## Goal

让正文阅读的排版（字号/行距/字体/宽度）与配色（主题模式）可按个人偏好调整——对应 ALDR 偏好域的阅读器/主题/字体子集，同时把设置中心「外观」「阅读」两个占位分类填上真实内容（用户 2026-10-16 指令：把阅读体感做一下）。

## Background（已确认事实）

- styles.css 已有 tokens 体系（--accent/--radius/--space 等，2026-10-16 建立）；正文排版目前为硬编码默认值。
- 设置中心外观/阅读分类为占位说明卡（settings-center 任务预留）。
- 当前亮/暗跟随系统（prefers-color-scheme 媒体查询），无手动覆盖。
- 配置存储沿用 settings.ts JSON 模式；**排版偏好属 UI 状态，由 renderer 直接应用 CSS 变量，不经主进程**——与桥接/DoH 的主进程设置不同源（新建 renderer 本地 prefs 模块 + localStorage，键 `ldd-reading`）。

## Requirements

- **R1 排版**（阅读分类）：正文字号（14–20px 步进 1，默认 16）、行距（1.5/1.7/1.9，默认 1.7）、正文字体族（系统默认/衬线/无衬线/等宽，默认系统）、阅读宽度（全宽/960/1120/1280px，默认 1120）。改动即时生效（CSS 变量）+ localStorage 持久化。
- **R2 主题模式**（外观分类）：跟随系统/亮/暗 三选（默认跟随系统）——亮色主题需补齐（当前仅暗色链路完整时此为最大工作量项）。
- **R3 应用范围**：正文渲染区（PostItem cooked、标题、时间轴）+ 全局底色/前景；控件区保持 tokens 不变。
- **R4 设置中心**：外观/阅读分类占位卡替换为真实控件（分段选择/滑杆），即时生效无需保存按钮；恢复默认按钮。

## Acceptance Criteria

- [ ] **AC1** 调整字号/行距/字体/宽度，正文即时变化；重启后保持。（待人工）
- [ ] **AC2** 主题模式三选生效：亮/暗/跟随系统；亮色下全部页面可读（无暗色残留文本）。（待人工；全站颜色已集中走 CSS 变量，残留风险低）
- [ ] **AC3** 设置中心外观/阅读分类为真实控件，含恢复默认。（待人工目测）
